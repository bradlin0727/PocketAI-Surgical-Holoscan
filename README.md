# PocketAI-Surgical-Holoscan

Checked by Brad Lin

## 🚀 Project Overview
Leveraging the ADLINK Pocket AI (RTX A500) enables real-time AI applications in medical imaging and surgical robotics. This portable solution provides the high-performance GPU acceleration needed for low-latency diagnostic processing and precise robotic control at the point of care.

## 🛠️ Hardware & Environment
- **Hardware**: NVIDIA Pocket AI (RTX A500)
- **Host**: Windows 11 Laptop via Thunderbolt
- **Dev Env**: WSL2 (Ubuntu 24.04) + NVIDIA Holoscan SDK

## 📋 Planned Demos
1. Demo A: Leveraging the ADLINK Pocket AI (RTX A500) enables real-time endoscopic polyp detection with high precision and low latency. By processing high-resolution video streams at the edge, this solution provides immediate diagnostic support to clinicians during procedures.
2. Demo B: The RTX A500 offers the GPU acceleration required for real-time vision feedback in surgical robotics. It ensures synchronized data processing between sensors and robotic arms, maintaining the sub-millisecond response times necessary for minimally invasive surgery.
